# Grapito

Grapito is a 2D party-game based on physics and grapples.
Optimized for instant fun and back-to-back short games.
Race against your friends in this retro ascension where skills are built over broken friendships.

A Windows release is [available on itchi.io](https://shredeagle.itch.io/grapito).
